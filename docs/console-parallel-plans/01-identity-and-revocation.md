# 身份影响范围与会话撤销基础

负责人角色：身份基础 agent。预计工作量：3–5 人日。估算含实现、审查、CI 修复与验收，不是日期承诺。

## 启动条件

依赖 00 契约；基于 PR #32 合并后的主分支或显式依赖分支。

## 开发内容

- 从已完成的原生用户启停/删除撤销机制出发，形成可复用的身份影响范围接口，保留原生登录和本机模式兼容。
- 支持普通 IAM 用户、临时主体及可信父身份的索引/匹配；实际 OIDC 主体字段必须采用 03/04 与服务端确认的身份语义，不把 issuer/sub/email 自行等同于 IAM 用户。
- 定义目标请求门控、写入静止、提交期间登录屏障、撤销 epoch、过期墓碑回收以及客户端请求租约。影响范围未知时拒绝授权变更。
- 设计可被 02 调用的撤销执行器，保证确认/未知撤销目标、明确拒绝保留会话、自身变更响应后撤销、其他用户继续使用。
- 为临时凭据到期/替换提供生命周期接口；不在本包实现 OIDC 网络请求或刷新调度。
- 外部变化的主动检测只定义接入点，由 05 实现；不得把请求前验证描述为即时全局撤销。

## 文件和职责边界

拥有：`internal/console/native_iam_retirement.go`、对应测试、核心会话/客户端生命周期实现和新增身份索引文件。PR #32 未合并时先研究契约，不重复实现删除功能。

跨文件公共类型经 00 确认；UI、OIDC 客户端、IAM 后端和审计写入由其他工作包负责。

## 验收条件

- 并发登录、重复撤销、取消/登出、确认/未知/拒绝、自身响应断开均有确定性回归测试。
- 其他主体不会被撤销；已撤销 token 不因重新启用/重建/刷新而恢复。
- 活动写入与 multipart 清理仍受保护；墓碑/主体索引随生命周期回收，不持续增长。
- 请求租约保护客户端，替换/退休不会提前关闭仍在使用的连接；race 测试通过。

## PR 和合并顺序

一个契约/基础 PR，再一个必要的身份映射 PR；基础合并后 02、04 接入。

## 认领和交付规则

开始时读取本目录 README 与契约计划，在独立分支和独立 worktree 开发，确认依赖 PR 的实际合并状态。任务文件不是创建、推送或修改其他 agent 分支的授权；按当前用户授权完成本任务的开发和 PR。

只修改本计划拥有的文件。共享文件的改动整理为明确的接入补丁，交给指定拥有者合并；需要提前调整接口时，先更新契约并通知受影响任务，不自行改变已冻结语义。测试使用临时账户和存储，避免实际用户配置或数据。

每个 PR 写明问题、最终行为、验证结果、版本与限制。失败记录与未知结果须保留，不自动重放身份变更，不以管理员代查/代操作普通用户资源。文档和测试证据只声明实际运行过的组合。

交付时提供提交/PR、已完成验收、未解决项和接入要求。共享验收报告、主迁移文档、主前端文件与发布 pin 统一由集成/发行拥有者更新，避免并行覆盖。
