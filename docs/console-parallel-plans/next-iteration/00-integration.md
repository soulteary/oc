# 00 协调与集成

负责全局范围、契约、调度和组合质量，不重复实现其他 agent 的模块。

第一轮核对实际 main、工作树和已有任务；更新 registry。冻结 OIDC 临时客户端/主体契约后再授予 01 核心窗口。向 04 收取每项旧 Web 能力的处理结论：Web 替代、明确保留 CLI、或待用户决定；OIDC 不得删减。

按独立 PR 集成协议、认证、IAM、UI 和部署；公共 dispatcher/capabilities 只在后端能力和撤销验证通过后开放。集成前核对重叠文件和接口版本，集成后记录新源码并跑相关组合检查。跨仓库协议改动先确定能力探测与旧版本拒绝语义。

每次交接回答：交付是否可接入、哪些测试真实执行、哪些仍 skip、窗口是否归还、依赖任务何时可开始。状态 verified 需要准确范围与证据，不能写泛化“迁移完成”。

退出条件：任务均有负责人/依赖/证据，所有承诺能力在最终集成版本验证；发布与删除结论分别有门槛记录。外部通知窗口尚未完成时登记等待，不制造发行事件或改写历史。
