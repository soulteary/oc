# 05 部署保障、稳定性与发行配对

可立即调查支持矩阵、现有发布资产与升级夹具；最终认证依赖 01/02/03/04 集成完成。

先记录支持的 local/native/OIDC、直连 HTTPS、容器和代理范围。可信代理必须有显式信任配置；浏览器 HTTPS 不代表后端满足 SecureTransport。验证源 IP 等策略上下文变化，不把单 alias wildcard 服务当成独立用户部署。单实例与多实例支持分别声明；未支持的拓扑不默认开放。

交付脱敏审计事件、身份/动作/结果关联、外部权限变化检测与会话撤销语义；明确请求时检查与主动检查的差别。审计不可包含 secret/token/完整认证响应。启动/会话 hook 交 01/00，不在认证窗口编辑核心。

长期检查并发登录/刷新/传输/诊断、退出与关闭后的 goroutine/连接/任务/临时文件增长；预算在实验前登记，并保存原始测量，不能只报告“稳定”。UI 分离的体积/依赖收益用一致构建条件测量。

发布候选须包含配对 OC/OtterIO 所需协议、归档/镜像/校验和/来源/SBOM，实际运行承诺平台及 amd64/arm64 容器；交叉编译不能替代运行。真实 IdP profile、HTTP/TLS/CA、普通/native/OIDC 权限、持久化、旧版本升级、同版本 UI 回退及再次关闭均需准确记录。

发布 pin 只在相应资产认证后更新。patched fixture/source 通过不能认证正式发布对。发布按当时授权执行；本任务先完成候选和可审查结果。服务端降级另行验证数据/配置，尤其生命周期远端引用。

输出三种独立结论：可试部署、可默认关闭、可删除。缺项明确列出；向 06 提供真实发行 tag/date、支持范围、升级回退证据和尚未结束的通知窗口。
