# 真实协议持续集成

## 可立即开始

首批真实 Range、诊断脚本没有接入 CI；`TestOtterIOSTSIntegration` 未配置 `OC_OIDC_TEST_SERVER` 时跳过。默认 `go test` 不能代表真实 STS 已运行。

## 工作范围

- 将 `test-console-range-real.py`、`test-console-diagnostics.py` 和 OIDC opt-in STS 测试接入 CI，复用已构建的临时服务，或在独立 job 建立夹具。
- 区分 pinned clean 源码构建、补丁夹具与正式发行资产；记录 SHA、clean/modified 状态、脚本版本、平台和实际场景。正式资产不能仅靠操作者声明的源码标签认证。
- 上传独立机器报告及脱敏失败证据，确保 STS 测试实际执行而非 skip；所有退出路径清理进程、账户、临时数据和端口。
- 保留权限负例、上游证书验证与现有传输预算。不要用删负例、降低门槛或自动重试身份修改让 CI 变绿。
- 首批明确支持的平台和运行成本，再由 07 扩展最终发布矩阵；不把 macOS/Linux 通过声明成全平台认证。

## 拥有与边界

拥有 `.github/workflows/go.yml` 的本轮接入、专属 CI wrapper 和报告格式适配。测试脚本修复先通知各原始模块负责人。OIDC/存储生产逻辑不由本任务改动。

## 验收

CI 日志证明三类真实协议均执行；管理员/普通 IAM 诊断差异、Range 版本权限、STS 策略缩权与禁止扩权均通过。失败时依旧产出可定位的证据，不泄漏 token。

## PR 顺序

真实协议 job 与失败报告 → 必要跨平台/资源清理修正。最终发行认证交 07。

## 交付规则

在独立 worktree 和分支开发，开始前核对 origin/main、目标任务、冻结接口及文件负责人。共享文件的接入补丁交 00 集成，不在其他 agent 分支切换或覆盖文件。

每个 PR 说明最终行为、相关验证、真实服务器/资产摘要、权限负例、未解决项及后续依赖。未知身份关系、未知变更结果或服务器缺少必要协议时保持拒绝，不自动重放身份修改。凭据不进入浏览器 JSON、日志、偏好或报告。真实验收仅使用临时账户、数据、配置和进程，不修改已有 alias 或部署。

本任务文件用于认领和交付，不表示实现、合并或正式发布已经发生，也不授权提前删除旧 Web。
