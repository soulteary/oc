# 集中部署审计与稳定性

## 提前开发与依赖

可立即开发审计 schema、独立模块、部署契约和负载夹具。认证事件接入依赖 04，撤销接入依赖 02；核心 hook 交 04/00。

## 工作范围

- 明确单实例直接 HTTPS 与可信代理模型、固定 external URL/CA、秘密配置读取、重启及配置回退；不直接信任任意转发头。
- 认证/刷新/管理事件审计记录主体、目标、动作、结果和关联信息，不记录凭据或敏感请求原文，不让普通用户读取他人审计。
- 定义可验证的外部权限/身份变化检测、频率与失联策略；区分请求前验证、主动检测和 IdP/STS 自身失效，不声称即时全局撤销。
- 补登录/刷新/校验与任务配额、客户端/连接回收观测，复用已有安全限制而不是重复实现。
- 多用户长期负载、上游失联、取消、停机/重启与恢复验收，报告采样时长、负载及资源回收趋势。多实例共享会话另立扩展任务。

## 文件归属

新增审计/运行保障模块、部署示例、专属负载脚本和任务文档。启动/会话文件由 04 集成，UI/总文档由 00 集成，发行 pin 由 07 管理。

## 验收与 PR

伪造代理头不能绕过 TLS/Host/Origin，普通用户不能读取他人审计/任务，token 不出现在日志；到期/撤销/限流/失联/恢复有确定性测试，长期资源无持续增长。部署契约/校验 PR → 审计与限流接入 PR → 主动检测与长期负载 PR。

## 交付规则

在独立 worktree 和分支开发，开始前核对 origin/main、目标任务、冻结接口及文件负责人。共享文件的接入补丁交 00 集成，不在其他 agent 分支切换或覆盖文件。

每个 PR 说明最终行为、相关验证、真实服务器/资产摘要、权限负例、未解决项及后续依赖。未知身份关系、未知变更结果或服务器缺少必要协议时保持拒绝，不自动重放身份修改。凭据不进入浏览器 JSON、日志、偏好或报告。真实验收仅使用临时账户、数据、配置和进程，不修改已有 alias 或部署。

本任务文件用于认领和交付，不表示实现、合并或正式发布已经发生，也不授权提前删除旧 Web。
