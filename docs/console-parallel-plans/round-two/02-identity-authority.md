# 权威身份关系与撤销执行器

## 可立即开始

#37 已提供原生 principal/IAM user 作用域 ledger、在途登录屏障和墓碑回收。本任务补其明确未实现的身份索引与影响范围，不重写 ledger。

## 工作范围

- 定义强类型主体/权威父身份/影响集合，适配当前原生身份，并为 04 的已验证 OIDC issuer/sub 提供独立命名空间。禁止 email/sub 推导 IAM access key。
- 查询权威服务端关系，区分已知空集、未知、过期快照和并发冲突；需要服务端原子关系/版本协议时先交付协议 PR，不以先查再写消除竞争。
- 抽取可供 03a/b/c 调用的影响范围执行器：目标登录屏障、请求门控、写入静止、确认/未知退休、明确拒绝保留、自身响应后退休。
- 保持 epoch、防旧登录提交、墓碑回收和客户端租约；活动写入/multipart 必须在退休前安全清理。
- 为 04 明确临时客户端替换/退休接口，由 04 实现刷新与存储客户端切换。外部主动检测交 06。

## 文件与接入

拥有 `identity_revocations.go` 及新增索引/撤销模块和对应测试。本轮第一批临时授权 02 独占 `server.go`、`session_clients.go`、`native_rotation.go` 和 `native_iam_retirement.go`，在窗口内直接接入必要补丁，00 不同时编辑。交付后窗口回收，再由 00 明确转交 04 独占认证核心；04 尚未启动。其他阶段未获得窗口的核心文件补丁交 00 集成。

## 验收

覆盖不同主体隔离、父/子与组影响、未知关系拒绝、并发登录/关系变更、拒绝/确认/失联结果、自身响应断开、重复撤销、epoch/墓碑有界回收。已有 native 全量 race 继续通过；旧 cookie 在重建/启用/刷新后不能复活。

## PR 顺序

身份契约/原生执行器 → 有服务端权威证据的关系适配。未知 OIDC 父关系不阻止其独立登录，但相关管理修改必须拒绝或保持禁用。

## 交付规则

在独立 worktree 和分支开发，开始前核对 origin/main、目标任务、冻结接口及文件负责人。第一批上述独占窗口内由 02 直接接入；窗口外共享文件的接入补丁交 00 集成，不在其他 agent 分支切换或覆盖文件。

每个 PR 说明最终行为、相关验证、真实服务器/资产摘要、权限负例、未解决项及后续依赖。未知身份关系、未知变更结果或服务器缺少必要协议时保持拒绝，不自动重放身份修改。凭据不进入浏览器 JSON、日志、偏好或报告。真实验收仅使用临时账户、数据、配置和进程，不修改已有 alias 或部署。

本任务文件用于认领和交付，不表示实现、合并或正式发布已经发生，也不授权提前删除旧 Web。
