# 旧 Web 默认关闭与移除门槛

## 提前准备与执行条件

当前只可准备门槛清单、弃用公告与回退验证设计。默认关闭和删除分别满足条件后交付；至少两个已通知发行周期及约定回退窗口不是代码合并能替代的条件。

## 工作范围

- 汇总 07 的发行范围、真实认证、普通/OIDC 身份与功能等价，以及仍保留的 CLI 替代。
- 核对公告发行日期、迁移反馈、回退窗口及现有部署受影响范围，不能用快速连续发版代替真实迁移时间。
- 先准备默认关闭旧 Web 的 OtterIO 独立 PR，仍验证回退入口与 S3/Admin/STS/健康/metrics 不受影响。
- 删除阶段另提 PR，移除 Web RPC/assets/upload/download/ZIP 与仅其依赖；检查构建、配置、路由、文档和发行包残留。
- 必需既有能力若决定废弃，应由用户明确批准并公告，不能通过重命名范围绕过迁移条件。

## 文件归属

OtterIO 独立 worktree/分支；旧 Web 路由、资源、配置、构建及对应测试。OC 兼容/迁移说明交 00/07，发布 pin 不由本任务更改。

## 验收与 PR

门槛证据/公告清单 PR → 满足条件后的默认关闭 PR → 满足后续窗口后的删除 PR。旧 Web 关闭下完整替代已通过，回退演练真实完成，核心服务路由/CLI 仍通过，发行资产无旧 Web 残留。尚未满足条件时明确标为等待，不能提前开始删除。

## 交付规则

在独立 worktree 和分支开发，开始前核对 origin/main、目标任务、冻结接口及文件负责人。共享文件的接入补丁交 00 集成，不在其他 agent 分支切换或覆盖文件。

每个 PR 说明最终行为、相关验证、真实服务器/资产摘要、权限负例、未解决项及后续依赖。未知身份关系、未知变更结果或服务器缺少必要协议时保持拒绝，不自动重放身份修改。凭据不进入浏览器 JSON、日志、偏好或报告。真实验收仅使用临时账户、数据、配置和进程，不修改已有 alias 或部署。

本任务文件用于认领和交付，不表示实现、合并或正式发布已经发生，也不授权提前删除旧 Web。
