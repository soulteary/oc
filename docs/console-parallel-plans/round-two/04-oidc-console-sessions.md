# OIDC 控制台登录与临时客户端

## 依赖

#38 协议客户端已经合并，先复用 `internal/oidc`。依赖 02 冻结身份/生命周期契约；核心文件须经 00 转交独占窗口。第三方 IdP 调查和端到端夹具可提前做。

## 工作范围

- 新增独立 OIDC 认证模式、启动配置、授权跳转、精确回调和错误状态；保留 local/native 默认行为。
- HttpOnly 随机 binding cookie、Secure/SameSite、Host/Origin/CSRF、参数重复拒绝、OAuth error、回调重放与过期登录拒绝。
- 每个用户使用独立 STS token/存储客户端/偏好/任务；不借启动 alias 的身份，不输出任何 secret/session/refresh token。
- 按 token/STS/固定期限建立会话硬到期；单次并发刷新、安全替换客户端，保留旧客户端在途租约，过期/退出/撤销不能提交迟到结果。
- 刷新失败关闭会话并清理客户端/任务；明确 OC 登出、IdP 登出、STS 到期的不同语义。
- 使用经过验证的 issuer/sub 独立身份键；未知原生父映射时保留相关 IAM 修改禁用，不猜测父身份。
- 登录与状态 UI 补丁交 00；OIDC token 校验语义不自行放宽。第三方 IdP 不符合当前 RS256/HTTPS 同源发现时先明确支持范围及必要独立协议变更。

## 验收与 PR

两个实际用户权限/偏好/任务隔离、退出不影响他人，回调安全负例、到期/刷新/关闭竞争和租约回收 race；真实 IdP、单/双 HTTPS 存储入口与独立 CA。登录/回调 PR → 客户端生命周期/刷新 PR → UI/端到端认证 PR。若登录 PR 尚无安全会话生命周期，仅交付未开放的基础模块，不发布可用登录入口。

## 交付规则

在独立 worktree 和分支开发，开始前核对 origin/main、目标任务、冻结接口及文件负责人。共享文件的接入补丁交 00 集成，不在其他 agent 分支切换或覆盖文件。

每个 PR 说明最终行为、相关验证、真实服务器/资产摘要、权限负例、未解决项及后续依赖。未知身份关系、未知变更结果或服务器缺少必要协议时保持拒绝，不自动重放身份修改。凭据不进入浏览器 JSON、日志、偏好或报告。真实验收仅使用临时账户、数据、配置和进程，不修改已有 alias 或部署。
