# 原生 IAM 组管理与影响范围

## 依赖与提前工作

可立即调查现有服务端组协议并建立夹具；修改开放依赖 02、00 冻结公共接口。与 03a/03c 仅在新增专属文件上并行。

## 工作范围

- 组成员增删、组启停、删除与条件组策略绑定。
- 依据权威成员/策略关系求真实影响集合。Allow/Deny 改变都可能改变权限；不能用“启用只增权”等动作名称代替影响分析。
- 原子协议覆盖成员/策略竞争；缺 revision、条件绑定或可靠关系保护时拒绝不安全修改并提出服务端任务。
- 使用 02 门控/撤销相关主体，不影响无关用户，恢复组权限不恢复旧 cookie。
- UI 准确显示目标、关系与确认范围，接入交 00。

## 文件归属

新增组辅助/handler/测试、`buildscripts/console_iam_groups_acceptance.py`；不修改用户/服务账号模块或共享总 dispatcher。

## 验收与 PR

管理员/普通/deny，成员同时增删、Allow/Deny 交错、目标自身、未知关系、失联/冲突、受限组；真实单/双 HTTPS 和默认只读/CSRF。先成员与影响范围 PR，再状态/删除和条件绑定 PR，不把三个动作一起无条件开放。

## 交付规则

在独立 worktree 和分支开发，开始前核对 origin/main、目标任务、冻结接口及文件负责人。共享文件的接入补丁交 00 集成，不在其他 agent 分支切换或覆盖文件。

每个 PR 说明最终行为、相关验证、真实服务器/资产摘要、权限负例、未解决项及后续依赖。未知身份关系、未知变更结果或服务器缺少必要协议时保持拒绝，不自动重放身份修改。凭据不进入浏览器 JSON、日志、偏好或报告。真实验收仅使用临时账户、数据、配置和进程，不修改已有 alias 或部署。

本任务文件用于认领和交付，不表示实现、合并或正式发布已经发生，也不授权提前删除旧 Web。
