# 原生 IAM 用户改密与策略绑定

## 依赖与提前工作

后端能力调查和夹具可立即做；开放管理动作依赖 02 撤销执行器及 00 公共类型冻结。当前原生动作白名单仅用户创建/启停/删除、空组创建与服务账号创建，不应直接扩大白名单。

## 工作范围

- 管理员对普通 IAM 用户安全改密，保持用户启停状态，不调用会重新启用用户的 helper。
- 条件用户策略绑定/编辑，保留 revision/冲突语义；原子能力缺失时明确拒绝并提出服务端协议任务。
- 以当前会话身份调用；新凭据只在确认后一次返回，未知结果不回显输入秘密或未确认凭据。
- 通过 02 对影响主体执行撤销和登录屏障；自身修改响应后退休，其他用户继续使用。
- 提交 UI 动作、准确确认与错误提示补丁，由 00 集成。

## 文件归属

新增用户辅助/handler/测试和 `buildscripts/console_iam_users_acceptance.py`。公共类型、总 IAM dispatcher 与主 UI 由 00 集成，不改组/服务账号模块。

## 验收与 PR

管理员、普通用户、明确 deny、自身与他人、启用/停用状态、revision 冲突、缺协议及失联负例；单/双 HTTPS 与独立 CA、默认只读和 CSRF。先用户改密 PR，再条件绑定 PR；各能力后端及撤销验收通过后才开放 UI。

## 交付规则

在独立 worktree 和分支开发，开始前核对 origin/main、目标任务、冻结接口及文件负责人。共享文件的接入补丁交 00 集成，不在其他 agent 分支切换或覆盖文件。

每个 PR 说明最终行为、相关验证、真实服务器/资产摘要、权限负例、未解决项及后续依赖。未知身份关系、未知变更结果或服务器缺少必要协议时保持拒绝，不自动重放身份修改。凭据不进入浏览器 JSON、日志、偏好或报告。真实验收仅使用临时账户、数据、配置和进程，不修改已有 alias 或部署。

本任务文件用于认领和交付，不表示实现、合并或正式发布已经发生，也不授权提前删除旧 Web。
