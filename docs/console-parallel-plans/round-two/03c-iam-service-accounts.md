# 服务账号生命周期与父身份影响

## 依赖与提前工作

可立即调查协议和建立临时账号夹具；动作开放依赖 02 的权威关系与 00 冻结接口。保留当前已实现创建，不重复实现。

## 工作范围

- 服务账号启停、改密、限制策略与删除；保留服务端 root/目录/STS 限制和状态语义。
- 区分服务账号主体、权威父用户和相关临时身份；未知父关系保持拒绝，不从名称/邮箱猜测。
- 保留父策略与会话限制的授权交集，禁止服务账号策略扩权；并发父关系/策略变化必须由上游可靠协议处理。
- 调用 02 执行器正确撤销影响主体，新凭据仅确认后一次显示。未知结果不重试、不展示未确认密钥。
- UI 确认与权限提示交 00，不直接放开所有 service-account 动作。

## 文件归属

新增服务账号辅助/handler/测试、`buildscripts/console_service_accounts_acceptance.py`；共享 IAM/public types/UI 接入归 00。

## 验收与 PR

父用户/管理员/普通/deny、跨父用户禁止、状态保持、策略缩权/禁止扩权、父关系未知/变化、失联与冲突；真实单/双 HTTPS、CSRF/默认只读。启停/删除与影响范围 PR → 改密/限制策略 PR。

## 交付规则

在独立 worktree 和分支开发，开始前核对 origin/main、目标任务、冻结接口及文件负责人。共享文件的接入补丁交 00 集成，不在其他 agent 分支切换或覆盖文件。

每个 PR 说明最终行为、相关验证、真实服务器/资产摘要、权限负例、未解决项及后续依赖。未知身份关系、未知变更结果或服务器缺少必要协议时保持拒绝，不自动重放身份修改。凭据不进入浏览器 JSON、日志、偏好或报告。真实验收仅使用临时账户、数据、配置和进程，不修改已有 alias 或部署。

本任务文件用于认领和交付，不表示实现、合并或正式发布已经发生，也不授权提前删除旧 Web。
