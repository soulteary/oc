# Console parity development evidence handoff

The actual matrix is `docs/console-capability-matrix.json` (28 capabilities); there is no `console-parity-matrix.json`. This document maps existing harness checks to candidate development coverage. It does not modify matrix statuses or certify a release. Exact report binary/source hashes, supported topology, actor permissions and test scope must match each candidate. Clean builds are development binaries; published release evidence is separate.

At this handoff, OIDC Chromium/protocol evidence binds Console 4f32ddba and server ff6e66f. New native user lifecycle work is targeting b8404f29 Console with a newer server; final same-asset OIDC rerun is pending. Historical feature/settings/write reports do not certify b8404f29. Treat the following strings as stable harness anchors for a future validated evidence adapter, not fabricated gate results.
